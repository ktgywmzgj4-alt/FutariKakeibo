# 安全のきまり

**AIはこのファイルを書き換えないでください。**

## 人間の承認が要る操作

やる前に必ず止まって、何をするか説明し、はっきり「やってよい」と言われてから実行します。
**「前に許可をもらったから」は理由になりません。** その都度確認してください。

| 操作 | なぜ |
| --- | --- |
| TestFlightへのアップロード | Appleのサーバーへ配布される。取り消せない |
| CloudKitのProductionへのスキーマ反映 | **入れた項目は二度と消せない**。名前も変えられない |
| `main` へのマージ | 他の作業の土台が変わる |
| GitHub Secretsの変更 | 間違えるとビルドが止まる |
| リポジトリの公開・非公開の切り替え | 公開は事実上取り消せない |
| メール・DM・SNSへの投稿 | 相手に届く |
| 購入・決済 | お金が動く |
| データの削除（ファイル、ブランチ、CloudKitのレコード） | 戻せないことがある |
| 権限の変更 | 影響範囲が読めない |
| 法的な同意（規約への同意など） | 責任が生じる |

## 絶対にやらないこと

承認をもらっても、やりません。

- **秘密情報を指示ファイルやコードに書く** — APIキー、パスワード、証明書、トークン
- **秘密情報を会話に出す** — `.p12` や `.p8` の中身、パスワードの値
- **`git push --force` を `main` に対して行う**
- **CloudKitのProductionから項目を消す** — Appleの仕様上できない。試みないこと
- **テストを消して「通った」ことにする**
- **完成条件（`Docs/requirements.md`）を自分で書き換える**
- **`Docs/safety.md`（このファイル）を書き換える**
- **利用者への約束（このファイルの「利用者への約束」3つ）を黙って破る**

## 利用者への約束

アプリの画面とREADMEに書いてある約束です。技術的な都合で勝手に破らないでください。

1. **レシートの読み取りは端末の中だけで行い、文字を外部のサーバーへ送らない。**
   画像は「レシート画像を保存」がONのときだけ、縮小した1枚を残す。
   残した画像の置き場所は、この端末の中と、招待した相手だけが読めるiCloudに限る

2. **広告と外部の解析ツールを入れない**
3. **家計データはiCloudの、招待した相手だけが読める場所にのみ置く**

生成AIのAPIを使う案が出ていますが、**レシートの文字を外部へ送るなら1番の約束が変わります**。
その場合はプライバシーポリシーの改訂、App Storeでの開示、利用者の同意取得が先です。
コードを書く前に、人間と決めてください。

## 失敗したときの戻し方

| 状況 | 戻し方 |
| --- | --- |
| 作業中のファイルを壊した | `git checkout -- <ファイル>` |
| コミットしたが間違い（未push） | `git reset --soft HEAD~1` |
| pushしたブランチが間違い | ブランチを捨てて作り直す。`main` は触らない |
| `main` にマージしたが間違い | `git revert -m 1 <マージのハッシュ>` で打ち消しコミットを作る。**履歴は消さない** |
| CIが赤 | 直してpushし直す。マージはしない |
| TestFlightに悪いビルドを上げた | 消せない。**新しいビルドを上げて置き換える** |
| CloudKitに間違った項目を入れた | Productionからは消せない。**使わない項目として放置し、正しい名前で作り直す** |

最後の2つが、承認を必要としている理由です。
