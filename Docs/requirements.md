## レシートから記録する4つ

2026-09-03、人間が指定。**これがレシート読み取りの仕様です。**

| # | 記録するもの | 合格ライン |
| --- | --- | --- |
| 1 | いつの支出か（日付） | **必須**。外れたら不合格 |
| 2 | どこの支出か（店名） | 8割方合っていればよい。人が直せる |
| 3 | 幾ら使ったか（合計金額） | **必須**。ここが違うと家計簿として使えない |
| 4 | 支出の種類 | 明細から推測する。外れても人が選び直せる |

**明細そのものは記録しません。** 種類を推測するための材料であって、
保存もされず、金額も画面に出しません。

金額と日付が外れた実例が出たら、**そのレシートからテストを起こしてから**直すこと。

## 守ること（機能以外）

| # | 内容 |
| --- | --- |
| N1 | レシートの読み取りは端末内だけで行い、文字を外部のサーバーへ送らない。画像は利用者がONにしたときだけ、縮小した1枚を端末とiCloud（招待した相手だけが読める場所）に保存する |
| N2 | 広告と外部の解析ツールを入れない |
| N3 | 家計データはApple のiCloud（招待した相手だけが読める場所）にのみ置く |
| N4 | iOS 17以降のiPhoneで動く |
| N5 | 文字を大きくしても、VoiceOverでも使える |
| N6 | オフラインでも記録できる。通信は同期のときだけ |

N1〜N3は**利用者への約束**です。破るなら、プライバシーポリシーの改訂と
App Storeでの開示、利用者の同意取得が必要になります。勝手に破らないでください。
