# 書き方の決まり

アプリに出る日本語と、コミットメッセージ・ドキュメントの書き方です。

## アプリに出る日本語

読む人は、家計簿の専門用語を知りません。

### 守ること

- **カタカナ語を避ける** — 「トランザクション」ではなく「支出」
- **命令ではなく説明** — 「入力せよ」ではなく「入力してください」
- **何が起きるかを言う** — ボタンは「保存」、押した後は「保存しました」
- **失敗は、原因と次にすることを言う**

### 悪い例と良い例

| 悪い | 良い |
| --- | --- |
| エラーが発生しました | このiPhoneに保存できませんでした。空き容量を確かめてください |
| 同期失敗 | 同期できませんでした |
| Invalid input | 内容と1円以上の金額を入力してください |
| データを削除しますか？ | この支出を削除しますか？ 削除後は元に戻せません |

### 呼び名

- 2人の初期値は **そら** と **つばさ**（架空の名前。実在の人を思わせない）
- アプリの名前は **ふたり家計簿**
- 相手のことは「パートナー」ではなく「相手」（設定画面の項目名を除く）

## コミットメッセージ

英語で書きます。**何をしたかではなく、なぜそうしたかを書いてください。**

- 1行目は50字前後の要約。ピリオドは付けない
- 空行を1つ置いて、本文
- 本文には「何が壊れていたか」「なぜこの直し方にしたか」を書く
- 差分を読めば分かることは書かない

読む相手は、半年後にこの行を `git blame` で見る人です。

## ドキュメント

- 結論を先に書く
- 表が使えるところは表にする
- 「〜と思われます」を避け、確かめたことと推測を分けて書く
- **確かめていないことは、確かめていないと書く**
