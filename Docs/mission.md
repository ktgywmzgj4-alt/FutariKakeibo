# 何を作るのか

## ひとことで

**カップル2人が、お金の話でけんかしないための家計簿アプリ。**

## 誰のためか

一緒に暮らしている、または家計を一部でも共有している2人。
どちらも家計簿の専門知識はありません。

想定している人:

- レシートを溜めがちで、月末に「何に使ったんだっけ」となる
- 「これ、どっちが払った?」が曖昧なまま流れている
- 家計簿アプリを入れたことはあるが、入力が面倒で続かなかった

想定していない人:

- 個人事業の経費を管理したい人（税務の機能は作りません）
- 3人以上の世帯（2人に絞ることで設計を単純にしています）
- 資産運用や投資の管理をしたい人

## 何が価値なのか

3つだけです。これ以外は付け足しです。

1. **入力が軽い** — レシートを撮れば、店・日付・金額が埋まる
2. **どっちが払ったかが残る** — 折半と個人を分けて記録し、精算額が出る
3. **2人で同じものを見られる** — 片方が入れたら、もう片方にも届く

## やらないと決めたこと

判断がぶれないよう、明示しておきます。

- 銀行やクレジットカードとの自動連携（他社アプリの領域。個人開発では維持できない）
- 広告
- 3人以上の共有
- レシート画像の保存（プライバシーを守る約束。詳しくは `Docs/safety.md`）
