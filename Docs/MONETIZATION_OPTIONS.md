# 無料機能と将来の有料機能：3案

価格は未設定です。課金実装も行っていません。

## 案1：コア無料＋便利機能プレミアム（推奨）

### 無料

- 2人共有
- 手入力の支出記録（件数制限なし）
- 共同予算、カテゴリ集計、精算額
- 基本カテゴリ
- 直近3か月の閲覧
- 月10〜20回程度のレシート読み取り

### 有料候補

- レシート読み取り上限解除
- 全期間の詳細分析・前年比較
- カスタムカテゴリ、複数予算、定期支出
- ホーム画面ウィジェット
- CSV/将来のPDFレポート

### 評価

無料のままでも「2人で家計を共有する」という中心価値を失わず、継続利用後に便利機能で収益化できる。最初の公開方針として最も自然。

## 案2：無料版＋買い切り「ずっと使える拡張パック」

### 無料

- 案1と同じ基本機能
- レシート読み取りは少ない月間上限

### 買い切り候補

- 読み取り上限解除
- 全期間分析
- カスタムカテゴリ・定期支出・ウィジェット

### 評価

家計簿で毎月課金されたくない利用者に伝わりやすい。一方、CloudKit運用や将来の外部AIなど継続費用が発生すると採算調整が難しい。

## 案3：基本無料＋「ふたりプラス」サブスクリプション

### 無料

- 手入力、基本共有、今月の予算・精算
- 履歴期間や高度分析を制限

### 有料候補

- 無制限履歴・分析
- 定期支出の自動化、将来の高度なレシート解析
- 旅行・引越し・結婚準備など目的別共同予算
- バックアップ確認、複数家計スペース

### 評価

将来、外部AIや継続的なサーバー費用が生じる段階に向く。ただし初期MVPでは価値検証前のため導入しない。

## 現時点の推奨

まず全MVP機能を無料で2人が1〜2か月使い、継続率と「なくなると困る機能」を確認する。その後、案1を基準に機能境界を決める。価格・無料上限・StoreKit実装は別途承認を得てから行う。
