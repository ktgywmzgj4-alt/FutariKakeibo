# 2人用MVP テスト計画

## P0：公開を止める条件

1. 起動・初期設定・再起動
2. 1円、999円、10万円、999万9999円の保存
3. A/B双方から追加・編集・削除
4. 招待されていないApple Accountからアクセス不能
5. アプリ削除・再導入後のCloudKit再参加
6. Production CloudKit環境での共有
7. Releaseビルドでのレシート撮影
8. クラッシュ、データ消失、重複、削除済み支出の復活がない

## P1：初回TestFlightで重点確認

- 0件、1件、100件以上の一覧
- 月またぎ、年またぎ、うるう日
- 予算ちょうど、超過、予算変更
- 端数のある折半（例：1001円。現在は整数除算のため、1円は支払者負担として残る）
- 同じ支出を2台で編集
- 圏外で連続追加・削除後に復帰
- iCloud Drive容量不足、iCloud未ログイン
- カメラ権限拒否、低照度、斜め・長いレシート
- OCR候補を修正せず保存しそうにならないか
- CSVをNumbers/Excelで開いた時の文字化け

## 合格基準

- P0が全件成功
- P1に既知のデータ消失問題がない
- 主要操作でクラッシュ0件
- OCR金額候補の正答率を実レシートで記録し、誤読時も修正可能
- TestFlight Feedbackに再現手順を残せる状態
