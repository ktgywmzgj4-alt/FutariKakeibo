## App Store に出る名前と、ポリシーに書く運営者名

| | App Store の販売者名 | ポリシーの運営者名 |
| --- | --- | --- |
| 決まり方 | 個人で登録した場合は、**法的な氏名**が出る。Apple の登録の説明: "Your personal legal name is needed so that you can enter into contracts with Apple. Your name will be displayed as the seller name of your apps on the App Store." 屋号やニックネームには変えられない | 利用者が決める。運営者がだれか分かる書き方にする |
| 推奨 | — | **販売者名と同じ氏名にする。** App Store で見た名前とポリシーの名前がそろい、問い合わせた人が迷わない。屋号を使いたいときは「屋号（運営者: 氏名）」と並べて書く |

- 氏名の書き方（漢字・ローマ字）と、問い合わせ用の**専用のメールアドレス**は、最終確認の項目として残す（利用者の情報待ち）
- 住所や電話番号をポリシーに載せる必要があるか（個人情報の保護に関する法律で公表を求められる事項に当たるか）は法律の判断なので、この原稿には書いていない。必要かどうかは専門家か公的な窓口で確かめる

## 掲載先の推奨: GitHub Pages（このリポジトリとは別の、公開用の小さなリポジトリ）

| 候補 | 費用 | よい所 | 気をつける所 |
| --- | --- | --- | --- |
| **GitHub Pages（公開用の別リポジトリ）**（推奨） | 無料 | 広告が出ない。直した履歴が残り、ポリシーの改定の記録になる。Claude が PR で直せる。アプリの変更とポリシーの変更を同じ流れで確かめられる | リポジトリも Pages も誰でも読める（ポリシーとサポートはもともと公開するもの）。URL に GitHub のユーザー名（ktgywmzgj4-alt）が出る |
| GitHub Pages（このリポジトリ） | 無料 | 足すものが少ない | 開発の記録と同じ場所になる。将来このリポジトリを非公開にすると Pages が止まり、ポリシーのURL（App Store の必須項目）が切れるおそれがある（GitHub の料金の説明はこの環境から読めず、未確認） |
| Google サイト | 無料 | 画面で作れる | 履歴が見えにくい。Claude が直せない |
| Notion の公開ページ | 無料 | 手軽 | URL が長い。サービスの都合で表示や公開の条件が変わりうる |

公開の手順（利用者が原稿を確かめたあと）:

1. 利用者が公開用のリポジトリを作る（または、作ることを Claude に頼む）。コミットに使うメールは、いまと同じ Apple の非公開リレーのアドレスか、GitHub の noreply のアドレスにする
2. 確かめた原稿に、氏名・メール・日付を入れて置き、Pages を有効にする
3. 出たURLを、App Store Connect（プライバシーポリシーURL・サポートURL）とアプリの「データとプライバシー」（R2）に入れる
