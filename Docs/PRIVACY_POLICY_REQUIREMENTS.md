# プライバシーポリシーに必要な項目

公開URLに掲載する最終文面には、以下が必要です。運営者名と問い合わせ先は未確定のため、勝手に記入していません。

AppleはApp Storeの商品ページに公開アクセス可能なプライバシーポリシーURLを必須としている。
参考: https://developer.apple.com/app-store/app-privacy-details/

## 必須項目

1. 運営者名または事業者名
2. 問い合わせ用メールアドレス
3. 適用対象アプリ名「ふたり家計簿」
4. 取得・処理するデータ
5. 利用目的
6. 保存場所と保護方法
7. 第三者提供・委託の有無
8. CloudKit / Appleへのデータ送信
9. 保存期間
10. 利用者による閲覧・訂正・削除方法
11. 共有相手を招待・解除した場合の扱い
12. 未成年者の利用方針
13. セキュリティ対策
14. 国外移転が発生する可能性とAppleの規約への参照
15. ポリシー変更時の通知方法と改定日

## 現在のデータ対応表

| データ | 処理 | 外部送信 | 目的 | App Store申告候補 |
| --- | --- | --- | --- | --- |
| 2人の呼び名 | 保存・共有 | 共有有効時はCloudKit | 画面表示・精算 | Name / App Functionality / Linked |
| 支出金額・予算 | 保存・共有 | 共有有効時はCloudKit | 家計管理 | Other Financial Info / App Functionality / Linked |
| 店名・メモ・カテゴリ | 保存・共有 | 共有有効時はCloudKit | 家計管理 | Other User Content / App Functionality / Linked |
| 覚えた店（店名・種類・店を見分ける電話番号と登録番号・合計の行の書き方・人が直した品の書き方と名前・種類） | 保存・共有 | 共有有効時はCloudKit | 次のレシート読み取りの候補入力 | Other User Content / App Functionality / Linked。品は人が直したものだけで、金額・日付は含まない |
| CloudKit参加情報 | Appleが共有管理。参加している人の名前（iCloudが教えてくれるとき）を共有の画面に出す | CloudKit | 合言葉（共有のURL）で参加する共有 | User IDの申告要否をApp Store Connectで最終確認 |
| 合言葉（招待） | 合言葉ごとに、共有の場所（共有のURL）と期限だけを1件置く。家計のデータは入れない | CloudKitの**Public Database**（アプリの利用者なら誰でも合言葉を指定して読める場所）。1日で期限切れ。使われたら「使われた印」を置き、発行した端末が合言葉を消す | 相手を招く | 家計のデータは含まないが、合言葉と共有のURLがあれば共有に参加できる。申告の要否をApp Store Connectで最終確認 |
| レシート画像 | 読み取り（OCR）は端末の中だけ。「レシート画像を保存」がONのときだけ、長辺1600pxまで縮小した1枚と小さな見本を残す（原寸の写真は残さない） | 共有有効時はCloudKit（招待した相手と共有する場所）。外部のサーバーへは送らない | 支出の詳細で見返す | Photos/Videos（保存がONのとき、App Functionality / Linked）。申告の要否をApp Store Connectで最終確認 |
| OCR文字列 | 保存前の画面だけ | 送信しない | 確認・修正 | 保存される項目のみ上記カテゴリへ含める |
| 通知（相手の支出） | 設定でONにしたときだけ、同期で届いた支出を見て、この端末の中で通知を作る（ローカル通知）。文に金額・店名・内容は入れない | 送信しない（2026-10-19 時点）。アプリを閉じているあいだの通知を入れると、AppleのプッシュでCloudKitから「変更があった」という中身の無い合図を受ける（端末の登録はAppleが扱い、開発者は受け取らない） | 相手の登録に気づく | 申告の要否をApp Store Connectで最終確認（開発者が集めるデータは増えない） |
| CSV | 明示操作時のみ保護付き一時作成し、共有画面終了後に削除 | 利用者が選んだ共有先 | データ持ち出し | アプリから自動送信しない |

Appleの定義では、給与・資産・負債などを含むその他の金融情報が「Other Financial Info」、自由入力内容が「Other User Content」、アカウント識別子が「User ID」に該当しうる。データをAppleのサービスから開発者が取得・利用する場合も、実際の取り扱いに沿って申告する。

## 現行実装に合わせた要点

- 広告トラッキングなし
- 第三者解析SDKなし
- 位置情報・連絡先・マイクを取得しない
- レシートの文字は端末の中だけで読み取り、外部のサーバーへ送らない
- レシート画像は「レシート画像を保存」がONのときだけ、縮小した1枚を端末と共有先のiCloudに残す。支出を消すと画像も消える
- 家計のデータはCloudKitのPrivate/Shared Database（家計簿を作った人のiCloudの中の、参加した人だけが読み書きできる場所）に置く
- CloudKitのPublic Databaseには、合言葉ごとに共有の場所と期限だけを一時的に置く（家計のデータは置かない）。合言葉は1回だけ・1日で期限切れ
- 共有は「合言葉（共有のURL）を知っている人なら参加できる」形。合言葉は相手にだけ伝える必要がある。参加している人は共有の画面で見られる
- 相手の支出の通知は、設定でONにしたときだけ。通知の文はこの端末で作り、金額・店名を出さない
- 利用者のCSV出力は任意操作
- 端末内データ削除機能あり

## 公開前に必要な追加判断

- 運営者名を個人名にするか屋号にするか
- 問い合わせ先メールアドレス
- CloudKitデータの具体的な保存期間
- 共有所有者が家計全体を削除する機能を初版に入れるか
- 退会・削除依頼をメールでも受け付けるか
- 公開用WebページのURL
